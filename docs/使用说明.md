# Enchantment Workshop / 附魔工坊 1.0.0 · 快速开始

## 安装

1. 准备 Paper 26.3 服务端和 Java 25。
2. 停服，将 `EnchantmentWorkshop-1.0.0.jar` 放入服务端的 `plugins` 文件夹。
3. 保留已有的插件数据目录，移出旧版 JAR，确保只加载一个版本。
4. 完整启动服务器，OP 输入 `/ew editor` 打开附魔工坊。

玩家使用原版客户端即可，不需要安装客户端模组。不要将测试工具 `EnchantmentWorkshopProbe.jar` 放进正式服。

## 制作附魔

可以选择「从空白创建」配置触发行为、条件和动作，也可以「从模板新建」或复制已有附魔。生效装备槽位和冲突附魔均支持多选。

条件选「无条件」可清空限制；动作选「装备飞行」后可设置每次起飞的耐久消耗量，`0` 表示不扣耐久。飞行无固定时限，仍要求装备耐久大于零；装备位于生效槽位时同时免疫摔落伤害。修改完成后点击「校验并保存」，检查预览，再点击「确认保存」。

新增附魔、删除附魔或修改名称、等级、槽位、冲突等注册属性，需要完整重启。仅修改效果、规则和说明且注册信息不变时，编辑器保存后自动生效。

## 常用命令

| 命令 | 用途 |
|---|---|
| `/ew editor` | 打开附魔工坊 |
| `/ew list` | 查看当前运行的附魔 |
| `/ew give 你的名字 lifesteal 3` | 获取吸血 III 附魔书 |
| `/ew validate` | 校验配置 |
| `/ew status` | 查看已保存配置的生效状态 |
| `/ew reload` | 重载效果与通用设置，不处理注册变更 |
| `/ew delete <ID>` | 预览删除整个附魔 |
| `/ew delete <ID> confirm` | 在两分钟内确认删除 |
| `/ew remove <ID>` | 仅移除主手物品上的指定附魔 |

编辑、给予和删除等管理命令需要 `enchantmentworkshop.admin` 权限，默认 OP 拥有。

## 配置文件

首次启动会在 `plugins/EnchantmentWorkshop` 生成：

- `config.yml`：通用设置。
- `enchantments.yml`：内置和自行添加的全部附魔定义。

编辑器保存前会校验、备份并检查文件修改冲突。删除原生附魔可能导致已有物品上的对应附魔丢失，删除前请备份世界与玩家数据。

完整步骤见 [附魔工坊入门](附魔工坊入门.md)，规则与飞行参数见 [可编程附魔说明](可编程附魔说明.md)，构建和完整命令见 [项目 README](../README.md)。
